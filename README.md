# @pong 🪽

Таймер и помодоро в трее macOS. Открытый код, бесплатно.

## Возможности

- Левый клик по ракетке в трее открывает окно таймера
- Время выставляется линейкой: тяни мышью, свайпай трекпадом или крути колесо. Линейка докатывается по инерции и встаёт на целое деление, трекпад щёлкает на каждом
- Переключатель min / sec: по умолчанию линейка в минутах (1–120), в секундах — от 1 до 120 секунд
- Последнюю минуту линейка сама идёт по секундам, а после конца возвращается к минутам
- В трее ракетка вырезана из квадрата цвета строки меню, а мяч красный
- На старте подача: мяч улетает с ракетки вдаль, сразу идёт время, а квадрат растягивается в капсулу
- Пока таймер идёт, ракетка в трее раскрывается в капсулу с обратным отсчётом: на работе она цвета строки меню, на отдыхе красная, на паузе контуром
- Трекпад отзывается на старт, паузу и отмену
- Кнопки: старт/пауза, отмена, помодоро
- Помодоро: количество циклов, время работы, время отдыха. После последней работы отдыха нет
- В конце фазы звучит «пинг» или «понг» и приходит уведомление
- Правый клик — меню: запуск при входе, выход
- Время считается от момента окончания, поэтому не сбивается после сна Mac

## Установка

1. Скачай `pong-x.y.dmg` из [Releases](../../releases) и открой.
2. Перетащи `@pong 🪽` на ярлык «Программы» и извлеки образ.
3. Приложение не нотаризовано, поэтому при первом запуске macOS его заблокирует. Открой через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

Автозапуск: правый клик по иконке → Launch at Login.

## Клавиши в окне

| Клавиша | Что делает |
| --- | --- |
| Пробел, Return | Старт / пауза / дальше |
| ← → | Минута или секунда меньше / больше |
| Esc | Закрыть окно или вернуться со страницы помодоро |

## Сборка

Нужен Xcode 16 или новее.

1. Открой `Pong.xcodeproj`.
2. Выбери схему `Pong › My Mac`.
3. Cmd+R.

### DMG для релиза

1. В Xcode: Product → Archive → Distribute App → Custom → Copy App.
2. `scripts/make-dmg.sh путь/к/pong.app` — образ появится в `build/pong-<версия>.dmg`.

Фон окна берётся из `assets/dmg-background@2x.png` (1200×800). Раскладку окна выставляет Finder, поэтому при первом запуске macOS спросит, можно ли терминалу управлять Finder.

## Как устроена анимация трея

Сначала подача (`TimerModel.serve`): ракетка бьёт по мячу, и время сразу пошло. Мяч за 0.3 с улетает вдаль, уменьшаясь, и только потом трей раскрывается в капсулу. Остаток округляется вверх, поэтому капсула всё равно показывает полное время. Дальше плавный старт складывается из трёх слоёв, и у каждого своё время:

1. **Ширина кнопки.** `NSStatusItem` не умеет анимировать длину, поэтому `StatusItemController` ведёт её своей пружиной: каждый кадр экрана (`CADisplayLink`) длина сдвигается на шаг. Физика та же, что у SwiftUI `.spring(response: 0.42, dampingFraction: 0.75)`.
2. **Фон капсулы** проявляется сразу.
3. **Время** въезжает снизу с увеличением через 0.1 с, когда капсула уже раскрылась. Дальше цифры меняются через `.contentTransition(.numericText)`.

Числа пружин лежат в `Theme.swift` → `Motion`.

## Файлы

| Файл | Что внутри |

| `TimerModel.swift` | Таймер, помодоро, настройки, формат времени |
